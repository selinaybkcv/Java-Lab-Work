# ☕ Java Lab & Assignment Coursework

This repository contains my weekly laboratory exercises, assignments, and practice code developed during my **Computer Engineering** coursework.

---

## 📂 Laboratory Exercises & Assignments Overview

| Folder | Topic / File | Description |
| :--- | :--- | :--- |
| **Assignments** | `DungeonCrawler.java`<br>`ExamGrade.java` | Simulates a role-playing mini-battle system featuring character classes (Warrior, Rogue, Ranger, Mage), String formatting, tag generation, damage mechanics, and HP calculations.<br>Calculates weighted average scores (40% midterm, 60% final) and determines letter grades while validating input constraints and handling automated fail states. |
| **Lab-1** | `Encoder.java`<br>`Decoder.java` | Encodes user-input integers using an arithmetic linear transformation formula.<br>Decodes transformed integers back to their original values by reversing the arithmetic transformation formula. |
| **Lab-2** | `ParkingFee.java` | Calculates rounded hourly rates and tiered parking fees based on vehicle classifications (Motorcycle, Car, Minibus) and time thresholds. |
| **Lab-3** | `CheckDigit.java` | Extracts individual digits from a 4-digit code using ASCII character arithmetic (`char - '0'`), computes their sum, and appends a mod-10 check digit. |
| **Lab-4** | `Blackhole.java` | Implements Kaprekar's routine for 3-digit numbers to reach the 495 constant by sorting digits into maximum/minimum combinations and iterating through arithmetic differences. |
| **Lab-5** | `StepCounter.java` | Tracks daily step counts using a sentinel-controlled `while` loop (terminating on `0`) to aggregate total steps and active days. |
